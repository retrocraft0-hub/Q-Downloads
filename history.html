Wie Q sich
entwickelt hat.

Die Historie zeigt dokumentierte Entwicklungsschritte. Sie unterscheidet bewusst zwischen einem bekannten Versionsstand und einer tatsächlich veröffentlichten Download-Datei.

FRÜHE PHASE

QDB 0.1 – 0.3

Die frühen QDB-Phasen sind dokumentiert. Im bislang geprüften Altbestand ist jedoch keine originale QDB-JAR vorhanden.

AUSBAU

Q-System & Q-Core

Aus frühen Zustands- und Interessenmodellen entstand eine größere Architektur mit Ressourcenbudgets und getrennten Verantwortungsbereichen. Einige frühe Quellstände und JARs sind erhalten, andere nur dokumentiert.

MODULARISIERUNG

Entity, Chunky und Player

Weitere Bereiche wurden als eigene Projekte getrennt, damit Funktionen, Portierungen und Tests unabhängig voneinander weiterentwickelt werden können.

01.10.2026

Öffentliches Q-Downloadarchiv

Die ersten öffentlichen Entwicklungsstände von System, Core, Chunky, Entity und Player wurden für mehrere Plattformziele im Downloadarchiv erfasst.

SEITDEM

Weitere Ports und Versionen

Neue Kombinationen aus Produkt, Plattform, Minecraft- und Java-Version werden nur dann im Finder angezeigt, wenn eine entsprechende Originaldatei tatsächlich veröffentlicht wurde.

Was im Downloadfinder zählt

Der Finder zeigt keine theoretischen oder nur geplanten Varianten. Eine Datei erscheint dort erst, wenn sie als reale Veröffentlichung im Q-Downloads-Katalog vorhanden ist.

PROJECT HISTORY

How Q
evolved.

The history records documented development steps. It deliberately separates a known version state from an original file that was actually published.

EARLY PHASE

QDB 0.1 – 0.3

The early QDB phases are documented, but no original QDB JAR has been found in the archive checked so far.

EXPANSION

Q-System & Q-Core

Early state and interest models evolved into a broader architecture with resource budgets and separated responsibilities. Some old sources and JARs remain, while others are documented only.

MODULARISATION

Entity, Chunky and Player

Additional areas became separate projects so features, ports and tests could evolve independently.

01 OCT 2026

Public Q download archive

The first public development builds of System, Core, Chunky, Entity and Player were recorded for several platform targets.

SINCE THEN

More ports and versions

New combinations of product, platform, Minecraft and Java versions appear in the finder only when a matching original file was actually published.

What counts in the download finder

The finder does not list theoretical or planned variants. A file appears only when a real publication exists in the Q-Downloads catalogue.
